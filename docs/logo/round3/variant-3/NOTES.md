# 变体 3「糖果光泽」· 工作记录

一句话：还是第一版那个黑框气泡 + 三块方块、原来的柠檬绿 / 米白 / 珊瑚，只是做工收紧了，每块像一颗被左上方光照着的软糖。

重新生成：`D:\conda\miniconda3\python.exe build.py`（SVG），`render.py`（png/ + sheet.png），
`compare.py <标签>`（和第一版并排 → wip/<标签>-compare.png），`pix.py <标签>`（32/24/16 放大对照）。

## 最终几何（1024 母版，64 单位网格，1 u = 16 px）

| 项 | 值 | 关系 |
|---|---|---|
| 气泡主体 | 832 × 720（52 u × 45 u） | 第一版 832 × 704，宽度不变 |
| 外框 = 缝 | 48（3 u） | 全图一个线宽 |
| 左列 : 右列 | 416 : 272 = 1.53 | ≈ 3 : 2 |
| 右列 上 : 下 | 256 : 320 | 4 : 5 = 1 : 1.25 |
| 外轮廓圆角 | R 176（11 u），Figma corner smoothing 50 % | 60 % 时米白块右上角的过渡长度（234）+ 缝角 36 超过块高 256，放不下 → 取 50 % |
| 方块外侧角 | 外轮廓向内精确等距偏移 48 的曲线（采样 + 法向偏移） | 真同心：任何位置黑框都是 48 |
| 方块之间的角 | 36 | = 0.75 × 外框 |
| 尾巴 | 外框左边直线下延；下垂 112（7 u），根部离左缘 208（13 u），斜率 ≈ 1 : 2 | 长度约第一版的 80 %（第一版 136 / 264） |
| 尾巴膝部 | 内凹圆弧 R 256；柠檬绿内侧同心 R 304 | 尾巴从底边“流”出来，不是贴上去的楔子 |
| 尾巴尖 | R 48 | = 缝宽 |
| 深色任务栏办法 | 外框外侧 12 px（= 外框 / 4）米白 #f6f1e4 @ 45 % | 浅色背景上看不见，#202020 上是一圈灰线 |
| 位置 | 主体原点 (106, 127)；alpha 质心 (511.4, 498.0) | 目标 (512, 496.6) = 中心上方 1.5 % |

配色：墨黑 #141412、柠檬绿 #d4f24a、米白 #f6f1e4 不变；珊瑚 #ff8a73 → #ff8f72（往暖桃偏一点点）。描边永远纯墨黑平涂。

糖果规则（每块一样，光从左上来）：
- 底色平涂；
- 柔光：同色系浅色（绿 #f7ffd0 / 米白 #fff / 珊瑚 #ffe2d6）@ 60 %，从块的左上边缘向内，偏移 18、模糊 14；
- 缝边内阴影：同色系深色（绿 #93b512 / 米白 #cbbf9f / 珊瑚 #e8693f）@ 35 %，右下边缘，偏移 18、模糊 18；
- 整块再叠一层左上 → 中部的白色 28 % → 0 线性渐变；
- ≤ 32 px：全部去掉，只留每块顶边 1 px 亮边（绿 #ecfb9f / 米白 #fffdf7 / 珊瑚 #ffc0ac）。

## 小尺寸（各自像素格上摆，直边全部落在整像素上）

| | 32 | 24 | 16 |
|---|---|---|---|
| 主体 | 30 × 26，从 (1,1) | 22 × 19 | 14 × 12 |
| 外框 = 缝 | 2 | 2 | 1 |
| 绿 : 右列 | 14 : 10 | 10 : 6 | 7 : 4 |
| 米白 : 珊瑚 | 9 : 11 | 6 : 7 | 4 : 5 |
| 外圆角 | 6（smoothing 50 %） | 4（50 %） | 3（圆弧） |
| 尾巴 | 4 级台阶 | 3 级 | 2 级 |
| 米白光圈 | 1 px @ 45 % | 同 | 同 |

尾巴在三个尺寸上都是“横 2 竖 1”的台阶（和母版 1 : 2 同一个角度），每级台阶末端补一个 45 % 墨黑像素，柠檬绿“舌头”跟着同样的台阶下去，每级末端补一个 50 % 绿像素。16 px 上三块颜色都在：绿 7×10、米白 4×4、珊瑚 4×5。

## 每一轮

**第 1 轮**　按网格从零写母版：主体 864 × 720（6 : 5），左右 432 : 288，外圆角 160 / smoothing 60 %，尾巴下垂 96、根部 192（正好 70 %）、膝部 R 320，三块加左上高光 + 右下内阴影。
和第一版并排看：太宽、尾巴被膝部圆弧吃掉，整体读成“一个盒子”而不是气泡；珊瑚右下的阴影偏红、发脏；比第一版大一圈。

**第 1b 轮**　主体收回 832 宽（和第一版一样），左右 416 : 272；尾巴放到 112 / 208、膝部 R 256；珊瑚阴影换成偏橙的 #e8693f、不透明度 0.45 → 0.35；按 alpha 质心把主体挪到 (106, 127)。
并排看：一眼是同一个图标了，尾巴是从框里长出来的。

**第 2 轮**　画 32 / 24 / 16：整像素主体，外框 = 缝，尾巴改成 1 : 2 台阶，柠檬绿舌头跟着下去，外侧 1 px 米白光圈，顶边 1 px 亮边。
放大到 ×8 看：16 px 三块颜色都认得出，深色背景上轮廓完整；但母版放大看，米白块右上角“捏”了一下，黑框在对角线上显得比 48 粗。

**第 3 轮**　原因是块的外侧角只是“近似同心”。改成把外轮廓的平滑角采样出来，沿法向精确向内偏移 48 作为方块外侧角（检查过：偏移后到外轮廓的距离处处 = 48.0）。还是显得捏——是 160 / 60 % 的角中间那段圆弧太小、两边过渡太长。换成 R 176 / 50 %，米白块右上角放得下了，角变圆润，和第一版的软度一致。光圈不透明度 0.55 → 0.45。
试了 32 px 用母版式的光滑尾巴：膝部圆弧把 4 px 的尾巴吃成一个小鼓包，不如台阶清楚 → 放弃（留在 wip/icon-32-smooth.svg）。

**第 4 轮**　三个小尺寸统一用台阶尾巴，每级末端补半透明像素，台阶在 1× 下看起来就是一条干净的斜线、不再是灰糊。做完横排组合（Geist Bold 转路径，大写高 368 ≈ 主体高的一半，字干 ≈ 79 ≈ 1.6 倍外框）、标题栏小标（A / C 主题）、png/、sheet.png。

**第 5 轮**　看 1024 原尺寸：白色高光在珊瑚上发“奶”，像蒙了层雾。高光改成每块自己的浅色（规则不变：同一偏移、同一模糊、同一不透明度），光带收窄（偏移 22 → 18，模糊 16 → 14）。再和第一版并排看一遍：配色、黑边、构图、情绪都在，块像软糖但不像玻璃。

## 自评（老实话）

- 缝和外框一样 48 粗以后，黑色比第一版多（第一版缝 36），整体比第一版“重”一点、方块略小。
- 尾巴是第一版的约 80 %，没压到 70 %：70 % 时（第 1 轮）气泡读成盒子，我宁可留长一点。
- 外轮廓 smoothing 只有 50 %，没到指导要求的 60 %（右上米白块放不下）。
- 米白光圈在纯白（#fff）背景上会露出很淡的一圈奶油色；在 #f3f3f3 任务栏上看不见。
- 16 px 右列只有 4 px 宽，绿 : 右 = 7 : 4，不是 3 : 2；珊瑚顶边 1 px 亮边让 16 px 的珊瑚看起来有两层颜色。
- 糖果效果用的是 SVG 滤镜（feGaussianBlur），不支持滤镜的转换器会变成平涂；交付的 PNG 已经烘焙好，不受影响。
- 标题栏 200 % 屏幕上我只给了 16 px 图的 2 倍预览，没有单独画 32 px 的标题栏小标（可以直接用 icon-32）。
