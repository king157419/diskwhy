## 1. 设计方向

**“石墨 + 鸢尾”**：偏暖的石墨灰深色底 + 一个冷色强调色。克制、安静，信息靠排版和明度层次说话。

| 决策 | 做法 | 理由 |
|---|---|---|
| 层次 | 侧栏 `bg-0` → 主区 `bg-1` → 卡片 `surface-1` → 悬停 `surface-2` → 按下/输入 `surface-3`，每级只差一点明度，再加 1px 半透明细边框 | 用户要求“层次靠背景明度差和细边框，不靠花花绿绿”；阴影只给浮层（悬停卡片、对话框、提示条） |
| 强调色 | **鸢尾蓝紫 Iris**（深色 `#8b8cff` / 按钮底 `#6c6df0`；浅色 `#5557e0`），全界面只有它一个品牌色 | 用户说“自己选一个强调色，不用橙”。三档色标已经占了绿 / 琥珀 / 玫红三个暖色区，强调色再用暖色会和“需判断 / 保留”混淆，所以刻意选冷色 |
| 三档色标 | 只出现在：小圆点标签（chip）、列表行图标底色（12% 透明度）、方块图色块。**不整行涂色** | DiskWhy 的差异化要突出但不能吵 |
| 方块图色块 | 深色主题用低饱和的“宝石色”（`#2b5f4c` / `#685330` / `#5f3a43` / `#393c48`），白字；嵌套越深越亮一点 | 第一版用 `#773840` 时 C:\ 根层几乎是一整面红墙，很刺眼；压低饱和度后仍能一眼分档 |
| 数字 | Geist 的等宽数字（`font-variant-numeric: tabular-nums`，`.num`）；路径 / 文件名用 Geist Mono（`.mono`）；大小单位全部由 `humanBytes` 输出 | 第一版数字也用了等宽的 Geist Mono，大号数字太“代码味”、而且 `28.38 GB` 在窄卡片里会折行，改成 tabular 数字后对齐不变、观感好很多 |
| 中文 | 字体栈 `Geist Variable → Microsoft YaHei UI → PingFang SC`：拉丁字母和数字用 Geist，汉字落到雅黑 | 本机不联网也能用；Geist 没有中文字形 |
| 动效 | 只有 120 / 180 / 240 ms 三档过渡（悬停、选中、按下缩放 0.985、页面淡入上移 4px、详情面板切换）；唯一的循环动画是扫描卡片的“呼吸 + 涟漪 + 进度条流光”；`prefers-reduced-motion` 时全部关掉 | 用户要求 150–200 ms、不要过度动画 |

每个档位都有 `-bg`（10–14% 透明度底）和 `-fg`（在底上可读的文字色）两个配套值，标签和图标底统一用它们。

### 2.2 其他令牌

- **字号阶梯**：11 / 12 / 13 / 14（正文）/ 16 / 20（页标题）/ 26 / 34（大数字）。
- **间距**：4px 基准：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。页面左右留白 32px，卡片内边距 20–22px。
- **圆角**：4（小标签）/ 6（小按钮）/ 10（按钮、输入、列表行）/ 14（卡片）/ 18（对话框）/ 999（圆点标签）。方块图块：根层 10、第二层 7、第三层 5。
- **阴影**：`--shadow-1`（分段按钮选中）、`--shadow-2`（底部操作栏）、`--shadow-pop`（悬停卡片、对话框、提示条，带 1px 边）。
- **布局**：侧栏 232px（窗口 < 1200px 时收成 72px 图标栏）、详情面板 380px（< 1360px 时 340px）、页头 68px。
- **主题**：`<html data-theme="dark|light">`，没有 `data-theme` 时跟随系统。默认深色；设置页可选“深色 / 浅色 / 跟随系统”，存在 localStorage（读不到就用默认），`index.html` 里有一小段脚本在样式加载前设好主题避免闪烁。Windows 标题栏跟着切换（`getCurrentWindow().setTheme`，为此在 capability 里加了 `core:window:allow-set-theme`；窗口配置默认 `"theme": "Dark"`）。
- **图标**：`lucide-vue-next`（界面）；方块图 Canvas 里用 lucide 的 SVG 路径数据画 `Path2D`（文件夹 / 文件 / 锁 / 云 / 图层 / 盾）。
- **应用图标**：新画了一个“被分成三段的磁盘环（可清理 / 需判断 / 保留）+ 中间强调色圆点”，侧栏品牌标和 exe 图标是同一个图形（源文件 `src-tauri/icons/icon-source.svg`，用 `tauri icon` 生成各尺寸，只覆盖了原有的那些文件）。

## 3. 信息架构

以前是一个页面塞满：顶栏一排按钮 + 黄色管理员横幅 + 归属条 + 各档合计 + 方块图 + 列表 + 详情 + 右下角抽屉。现在是**左侧固定侧栏 + 五个页面**：

| 页面 | 内容 |
|---|---|
| **概览** | 页头：标题 + 扫描信息 + 盘符选择 / 扫描文件夹 / 打开快照 / 保存快照 / 主按钮。未扫描：插画空状态 + 每个盘一张卡片（点了就扫）+ 三条原则。扫描中：呼吸感进度卡片。扫描后：**磁盘环**（整圈 = 卷容量，已用部分按三档分段）、**本次能腾多少**（大字“可以放心清理 32 GB” + 四档小卡片）、**已用空间归属**（堆叠条 + 五行明细 + 去重说明）、**最大的目录**（点一下直接跳到空间分析）、普通权限提示卡片、隔离区过期提示卡片 |
| **空间分析** | 工具条：上一级 + 面包屑 + “列表 / 方块图”切换。左边列表或方块图，右边详情面板 |
| **清理清单** | 左：分类（全部 / 可以放心清理 / 需要你判断，带项数和大小）+ “删到哪里”（回收站 / 隔离到其他盘 + 位置）。右：条目复选列表（“低风险 / 有代价”标签，review 项直接写“删了会失去：…”）。底部固定操作栏：已选 N 项 · 预计释放 · 删到哪里 · “预览要删的内容” |
| **隔离区** | 三个统计卡片（批次 / 占用其他盘 / 超过 7 天）+ 每批一张卡片（日期块、大小、原来在哪、位置、还原整批 / 彻底清空…二次确认） |
| **设置** | 外观（三种主题带缩略预览）、AI 推测（原来的表单 + 开关 + 隐私说明 + API Key 明文警告）、规则库与数据（规则条数、注册表软件数、权限、动作日志路径、版本、规则库警告） |

侧栏底部：权限状态（普通权限 + “以管理员重新启动”链接；管理员时显示绿色盾）、设置（带版本号）。清理清单和隔离区在侧栏上有数字角标，隔离区有过期批次时角标变琥珀色。

原来刺眼的黄色“以管理员重新启动”横幅，改成了侧栏底部的小状态块 + 概览页里一张说明卡片（“当前是普通权限，有 12.84 GB 量不到”）。

## 5. 方块图（Canvas）

- **布局**：仍是 `src/treemap.ts` 的 squarified + 嵌套（算法和单元测试没动），方块图组件传入自己的参数：容器标题栏 28px（放图标 + 名字 + 大小）、内边距 5px、容器至少 96px 才展开子块。
- **绘制**：每块向内收 2px（深层 1.5px）留出缝，`roundRect` 圆角（10 / 7 / 5），1px 半透明亮边；容器内部铺一层暗底再画子块；系统保留项叠细斜纹；“无权限（推算）”等归属块是深灰斜纹 + 盾牌图标。
- **块内排版**：大块（> 220×130）：20px 图标、15px 名字、13px 大小、右下角百分比（占当前视图），还能进去的大块左下角淡淡写“双击进入 →”；中块：15px 图标 + 12.5px 名字 + 大小 + 百分比；小块只写名字；再小就只有颜色。
- **悬停**：块提亮 + 1.5px 亮描边；**浮动卡片**（毛玻璃半透明底、`shadow-pop`、圆角 14）：档位标签 + 占比、名字、路径（等宽）、大号大小、这是什么、属于谁、“单击看详情 · 双击进入”。卡片靠近边缘时自动翻到另一侧。
- **选中**：2.5px 强调色描边 + 14px 柔光。
- **主题**：颜色全部从 CSS 变量读，切换主题 / 系统主题变化时重画；网页字体加载完再重画一次，保证 Canvas 里也是 Geist。
- 交互、键盘、读屏按钮、Backspace / Alt+← / 鼠标后退键上钻，全部沿用阶段 C 的逻辑。
