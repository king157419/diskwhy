# 第三轮 · 变体 1「原样精修」

一句话：还是第一版那个黑边对话气泡里装三块糖色方块，只是线一样粗、角一样顺、尾巴从框里自己长出来、整体摆正了。

## 几何（1024 母版，64 格：1 u = 16 px，所有坐标落在 4 px 细格上 → 256 px 时整像素）

| 外框 t / 缝 g | 44 / 44 | 同一粗细（第一版 48 / 36） |
| 左列 : 右列 | 408 : 272 | 3 : 2 |

## 迭代记录（每轮都和 concept-2 原图并排看：wip/rN.png、wip/rN-big.png、wip/pix-rN.png）

- **r1**：按简报字面：外框 = 缝 = 48、主体 864 × 720、外角 192 + 60 % 平滑、尾巴 112/224、米白细边不透明。看图：角看起来比第一版**紧**（squircle 同样半径显得更方），整体像电视机；48 的缝让方块像窗格；细边在深色底上像贴纸白边（那是变体 2 的事）；尾巴偏扁。
- **r2**：试了 7 组圆角 / 4 组尾巴 / 3 种线宽（wip/explore-*.png）。改成 外框 = 缝 = 44（比第一版外框略轻、缝略重，两者相等后整体墨量接近原图）；外角 220；尾巴改短胖（下垂 120、尖端 64）；细边降到 50 %。小尺寸：24 px 的 2/2 黑太多，尾巴里的绿色几乎没了。
- **r3**：60 % 平滑让柠檬绿顶边像圆顶、珊瑚底边几乎全是弧 → 外角 216 + 50 % 平滑（简报 ≈60 % 的折中，诚实记一笔）。24 px 做了 1/1 备选；32 px 尾巴改成更宽的台阶 + 4 px 胖尖，让绿色真正伸进尾巴。
- **r4**：主体从 852 宽收到 812（左右 408 : 272 仍是 3 : 2），整体轮廓比例回到第一版那种“近方”，放一起一眼还是它。24 px 定为 1/1（母版缩到 24 是 1.03 px），左右 11 : 8。
- **r5**：横排字：Geist Bold，大写高度从主体 0.56 降到 0.50，字干 ≈ 1.6 × 外框，不再压过图标；k–W 补 −64 字距。
