# DiskWhy logo · 第三轮美术指导（Opus，2026-10-07）

## 0. 用户的话（最高优先级）

- 第一轮看到方案 2：「思路很不错，很完美地把这个创意解释出来了，但是设计的艺术性上还是差一点。」
- 第二轮（灰绿色、去掉黑边的“高级感”变体）：「我觉得还都不如第一版呢。」

结论：用户喜欢的是第一版方案 2 的**样子**，嫌的是**做工**。这一轮是在第一版上**精修**，不是重新设计。

## 1. 必须保留的东西（改了就算失败）

参照：`docs/logo/concept-2/icon.svg`、`concept-2/sheet.png`、`concept-2/png/icon@1024.png`（动手前先用 Read 看这几张图）。

1. **构图**：对话气泡，尾巴在左下；里面三块方块——左边一整列大柠檬绿块，右上米白块，右下珊瑚块。大小关系不变（柠檬绿最大）。
2. **配色**：柠檬绿 `#d4f24a` 一族、米白 `#f6f1e4` 一族、珊瑚 `#ff8a73` 一族、墨黑 `#141412`。允许微调明度 / 饱和度让它们更和谐（例如珊瑚往暖桃色偏一点、别像警报红），但**一眼看上去必须还是这三个颜色**。不加新的主色，不换成灰绿 / 苔绿。
3. **粗墨黑外框 + 方块之间的墨黑缝**：贴纸感、卡通主题（C）的味道。不能去掉黑边。
4. **明亮、有趣、像糖果**的情绪。不能变“稳重”“商务”“高级灰”。

## 2. 要修的做工问题（第二轮美术指导的诊断，这部分是对的）

详见 `docs/logo/round2/BRIEF.md` §1（只用它的诊断，不用它对配色 / 风格的建议）。概括：

1. **比例随手定**：气泡宽高比、左右两列、右列上下，几个比例互不相关。→ 用 64 单位网格（1 u = 16 px），主要比例从一个简单关系里来：左列 : 右列 ≈ 3 : 2（或 φ），右列上 : 下 ≈ 1 : 1.25（让它像 treemap 而不像窗格）。
2. **线宽两种**：外框 48、缝 36，差一点又不相等，像失误。→ 外框和缝用**同一个粗细**（或者缝正好是外框的一半，二选一，全图统一）。
3. **圆角打架**：柠檬绿块外侧大圆角、内侧 28 的小圆角，一块砖两种角，像字母 D。→ **同心圆角**：方块的外侧角 = 外框外轮廓半径 − 外框粗细；方块之间相邻的内角统一用一个小半径（≈ 外框粗细的 0.75）。外轮廓用**连续曲率圆角（squircle / corner smoothing ≈ 60%）**，不用纯圆弧。
4. **尾巴像贴上去的楔子，所以像聊天软件**：→ 尾巴从外框左下角**自己长出来**：外框的圆角顺势延伸成尾巴，尾巴内侧（和柠檬绿块交界处）是一条顺滑的弧，尖端收圆（半径 ≈ 缝宽）。尾巴**短一点、胖一点**（长度约为原来的 70%），角度在所有尺寸上统一。
5. **深色任务栏上黑框消失**：→ 每个变体都要给出办法，并在 `#202020` 上验证轮廓完整（见第 3 节各变体）。
6. **渐变不统一**：大图有渐变、小图纯色，墨黑描边也加了渐变。→ 描边**永远纯墨黑**。色块要么全尺寸都是平涂，要么用同一个极轻的高光规则，小尺寸取中间色。
7. **视觉偏上偏左**：→ 按图形重心（alpha 质心）居中，重心放在画布中心上方约 1.5%。
8. **小尺寸**：16 / 24 / 32 在像素格上手画；规定什么时候去掉什么（例如 16 px 上缝宽 1 px、外框 1 px、尾巴固定 2×2 的台阶），三个尺寸的尾巴角度一致。16 px 上三块颜色必须都还认得出来。

## 3. 三个变体（是同一个图标的三种精修程度，不是三个新方向）

- **变体 1「原样精修」**：只做第 2 节的修正，平涂，不加任何新效果。目标：用户一看就说“这就是第一版，但更好看了”。深色任务栏的办法：外框外侧加一圈很细的米白描边（≈ 外框的 1/4），只在深色背景下才看得出来。
- **变体 2「贴纸版」**：在变体 1 的基础上，做成**模切贴纸**：墨黑外框外面再包一圈米白 / 白色的贴纸边（≈ 外框粗细的 0.6），右下方一个卡通主题那种**硬投影**（墨黑，向右下偏移，不模糊）。这是最“C 主题”的版本，深色任务栏上天然有白边。小尺寸（≤ 24）可以去掉投影、保留白边。
- **变体 3「糖果光泽」**：在变体 1 的基础上，每块方块加**同一个方向（左上）的柔和高光**和缝里极轻的内阴影，让方块像三颗糖 / 软胶按钮，更立体、更“可口”；外框仍是纯墨黑平涂。高光必须克制（不能像玻璃反光），并且所有尺寸用同一规则（≤ 32 px 只保留一条 1 px 的亮边）。深色任务栏办法同变体 1。

## 4. 交付（每个变体一个文件夹 `docs/logo/round3/variant-N/`）

- `sheet.png`（≈1600 宽）：**最左边放第一版方案 2 原图做对照**，然后是新图标的大图、浅色 `#f3f3f3` / 深色 `#202020` 任务栏上的 32 / 24 / 16、标题栏效果

至少画 → 渲染 → 自己看 → 改 4 轮。渲染用 Playwright + 本机 Edge（`D:\conda\miniconda3\python.exe`，参考 `docs/logo/concept-2/render.py` 和 `concept-2/build.py`——可以直接从它的生成脚本改起）。只在 `docs/logo/round3/` 下工作，不碰 `src/`、`src-tauri/`、`crates/`。

## 5. 判断标准（评审按这个打分）

1. 和第一版放在一起，**一眼还是它**（配色、黑边、构图、情绪都在）——不满足直接淘汰。
2. 和第一版放在一起，**明显更精致**：线宽统一、圆角顺、尾巴自然、比例舒服、不偏。
3. 16 px 在浅色和深色任务栏上都完整、三块颜色认得出。
4. 不那么像聊天软件（尾巴短胖、从框里长出来）。
